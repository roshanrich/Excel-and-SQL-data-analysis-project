# Data Analytics Projects Portfolio

This repository showcases my data analytics projects developed during my internship at OnSite Academy. It includes two projects focused on analyzing business sales data and healthcare appointment records using Microsoft Excel and MySQL.

## Projects

### 1. Vrinda Store Data Analysis — Microsoft Excel
- Cleaned and analyzed 30,000+ e-commerce records.
- Used PivotTables, XLOOKUP, slicers, and charts for data analysis.
- Built an interactive dashboard to explore sales performance, customer trends, and order fulfillment patterns.
- Organized data to support business reporting and data-driven decision-making.

### 2. Healthcare Appointment Analysis — MySQL
- Analyzed healthcare appointment records using SQL queries.
- Explored appointment trends and patient attendance patterns.
- Organized and summarized data to support reporting and identify useful patterns in appointment records.

## Tools & Technologies
- Microsoft Excel — Data Cleaning, PivotTables, XLOOKUP, Slicers, Charts, Dashboards
- MySQL — SQL Queries, Data Filtering, Aggregations, and Reporting

## Objective
To apply data analytics techniques to real-world business scenarios, extract meaningful insights from structured datasets, and strengthen my problem-solving and analytical skills.
